# Quick Container Tabs（便捷容器标签）

> 在背包、箱子和各类工作方块界面的上下两侧添加可点击的标签页，点击即可直接切换打开周围容器 / 工作方块，省去「关闭界面 → 走过去点击方块」的繁琐流程。

## ✨ 特性

### 基础功能
- **上方标签页**：识别周围容器类方块（箱子、木桶、熔炉、潜影盒、漏斗、发射器等）
- **下方标签页**：识别周围工作方块类（工作台、铁砧、附魔台、锻造台、切石机、织布机等）
- 上下两侧独立翻页按钮，支持分页浏览
- 鼠标悬浮可显示对应方块名称
- 扫描半径、单页显示数量均可配置调整

### 🎨 个性化设置（核心亮点）
1. **自定义标签图标**
   可以为每一个容器单独设置显示图标，**支持原版物品，也完全支持其他模组添加的物品作为标签图标**，不受物品来源限制。

2. **容器收藏置顶**
   每个标签附带收藏按钮，被收藏的容器标签，会固定显示在界面右侧独立区域，优先展示，不会被分页淹没，高频使用的箱子、机器可以一键置顶。

3. **丰富的配置面板（默认按键 `B`，打开配置菜单）**
   通过配置界面可对模组行为深度自定义：
- **扫描距离**：默认扫描距离为 4 格（原版生存玩家交互手长为4.5格，预留安全余量），可按需调大或缩小扫描范围；
- **标签显示优先级**：自定义各个容器、工作方块在标签列表里的排序优先级；
- **标签排布位置**：可以自定义标签上下布局、显示方向；
- **黑名单 / 排除列表**：屏蔽不希望出现的方块；
- **第三方模组兼容接入**：支持添加其他模组新增的容器、工作方块，纳入标签扫描识别范围。

## 📋 环境要求
- Minecraft: `1.21.1`
- NeoForge: `21.1.250`
- Java: `21`

## 🔨 构建方法
```bash
# Windows
./gradlew.bat build

# Linux / macOS
gradlew build
```
构建输出产物路径：`build/libs/qct-0.1.0-beta.jar`

## 📦 安装方法
将构建得到的 `qct-0.1.0-beta.jar` 复制到 Minecraft 的 `mods` 文件夹内，启动游戏即可加载本模组。

## ⚙️ 使用说明
1. 打开任意背包、箱子、工作台等方块UI，界面上下会自动生成附近容器与工作方块标签；
2. 鼠标悬浮查看方块名称，点击标签直接跳转打开对应容器；
3. 点击标签上收藏按钮，将常用容器固定到右侧专属收藏区域；
4. 按下键盘按键 `B` 打开配置菜单，调整扫描距离、优先级、布局、第三方方块兼容等全部参数。
